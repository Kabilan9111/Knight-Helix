# 🎯 The Problem

Large projects generate enormous amounts of execution information.

But the information is often fragmented across:

- Manual site reports
- DPRs
- Excel sheets
- Images
- Voice updates
- Task systems
- Evidence submissions
- Project schedules
- Field verification
- Different project tools

This creates a critical gap between:

> **WHAT WAS PLANNED**

and

> **WHAT IS ACTUALLY HAPPENING ON SITE**

By the time project teams understand what happened, a delay may have
already propagated into downstream activities.

SANCHALAN is designed to close that gap.
